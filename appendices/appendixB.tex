\section{A Prompt}
\label{app:second-prompt}

\begin{lstlisting}[caption={[A verbatim prompt]A prompt, set verbatim so that every character is the one that was sent.}, label=lst:app-prompt]
You are given the source of one class.
Answer with JSON only, using this schema:
  {"malicious": true|false, "reason": "<one sentence>"}
Judge the code, not the class name.
\end{lstlisting}
